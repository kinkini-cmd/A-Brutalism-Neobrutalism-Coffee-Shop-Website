☕ Brutal Coffee — React + Framer Motion

A bold and experimental coffee shop website built using Brutalism & Neobrutalism design principles with modern frontend technologies.

This project focuses on raw UI, strong typography, and punchy animations instead of traditional polished design.

🎯 Project Idea

Most websites aim for perfection — smooth, minimal, and predictable.

This project does the opposite.

👉 It intentionally breaks design rules to create:

Harsh layouts
High-contrast visuals
Playful but aggressive interactions
🚀 Features
⚛️ Built with React (Vite)
🎬 Animations powered by Framer Motion
🧱 Brutalist UI (raw, bold, structured)
🎨 Neobrutalist enhancements (colors, shadows, playful motion)
⚡ Interactive elements:
Button press animation
Card hover “jump” effect
Scroll reveal animations
Floating hero text
🛠 Tech Stack
React (Vite)
Framer Motion
HTML5 + CSS3
JavaScript (ES6)

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/your-username/brutal-coffee.git
cd brutal-coffee

Install dependencies:

npm install

Run the development server:

npm run dev
